# 绿植护眼小组件 GlassWidgets

零权限安卓桌面小组件合集，护眼绿植主题，一共 8 个：

1. **时间日期电量**（4×2）— 大字时钟+日期+电量，可选"圆润/细体"两种字重，点击跳转系统时钟
2. **月历**（3×3）— 当月日历，今天用绿色小圆点标出
3. **电量胶囊**（2×2）— 胶囊状进度条+百分比+状态文案，点击跳转电池设置
4. **闹钟快捷**（1×1）— 大图标按钮，点击直达系统闹钟
5. **音乐快捷**（1×1）— 配置时从已安装 App 里选一个，点击直接跳转（网易云/QQ音乐/随便什么）
6. **一句话手记**（3×2）— 桌面直接点开写一句话，本地保存，随时可改
7. **护眼倒计时**（2×2）— 点击开始 20 分钟倒计时，提醒你按 20-20-20 法则歇眼睛，再点一下重置
8. **倒数日**（2×2）— 自定义标题和目标日期，比如"距离期末考试还有 12 天"

每个小组件都可以单独设置**配色**（薄荷 / 森林 / 鼠尾草 / 抹茶 / 墨绿 五套绿植色系）和**透明度**，
桌面上放好几个可以各自设成不同风格。

## 权限

**不申请任何运行时权限**，AndroidManifest.xml 里没有一条会弹窗的 `<uses-permission>`：

- 时间用系统自带 `TextClock`，倒计时用系统自带 `Chronometer`，都是系统组件自己走的，不用自己起定时器
- 电量读的是系统的粘性广播 `ACTION_BATTERY_CHANGED`，不需要权限
- 月历、倒数日都是本地用 `java.time` 算出来的
- 音乐快捷组件里"选 App"用到的 `<queries>` 声明只是让系统告诉本 App 有哪些能打开的 App，
  这是编译期的可见性声明，不是运行时权限，安装和使用过程都不会弹任何权限对话框

## 用 GitHub Actions 编译 APK（手机操作流程）

1. 在 GitHub 新建一个仓库（比如叫 `GlassWidgets`）
2. 把这个文件夹里的所有文件上传上去（可以用 GitHub 手机 App 的「上传文件」，
   或者网页版拖拽上传，保持文件夹结构不变）
3. 上传完成后，进入仓库的 **Actions** 标签页
4. 应该会看到一个叫 `Build APK` 的工作流自动跑起来了（如果没自动跑，
   点进去手动点 `Run workflow` 也可以）
5. 等它跑完（一般 3~5 分钟），点进这次运行记录，下面 **Artifacts** 里
   会有一个 `GlassWidgets-debug-apk`，点击下载，是个压缩包，
   解压后里面就是 `app-debug.apk`
6. 手机上直接打开这个 apk 安装即可（小米可能会提示"未知来源"，
   允许安装就行，这个 apk 是用调试签名打的，可以直接装，不需要额外配置签名证书）

## 用法

- 长按桌面 → 小部件/挂件 → 找到「绿植护眼小组件」→ 拖到桌面
- 松手后会弹出配色+透明度设置界面，选好点保存
- 一句话手记：直接点组件本身就能改文字
- 护眼倒计时：点一下开始 20 分钟，再点一下重置
- 音乐快捷：第一次放的时候在配置界面点"选择 App"挑一个

## 之后想加/改的东西，随时可以说

- 想要真实天气 → 需要加一条 `INTERNET` 权限（是普通权限，装的时候不会弹窗，但我会先跟你说清楚）
- 想要读系统日历上的日程 → 需要加 `READ_CALENDAR`（这个是敏感权限，会弹窗申请）
- 想要计步 → 需要加 `ACTIVITY_RECOGNITION`（也是敏感权限，小米上通常还要额外开自启动才稳定）
- 想换字体、圆角大小、加更多配色，都是改资源文件，不涉及任何权限

这几样如果要加，我会提前说清楚加的是什么权限、干什么用，你来决定要不要加。
