# 磨砂小组件 GlassWidgets

零权限安卓桌面小组件合集。第一批包含两个小组件：

1. **时间日期电量·玻璃**（4×2）— 大字时钟 + 日期 + 电量
2. **月历·玻璃**（3×3）— 当月日历，今天用 `[ ]` 标出

两个小组件都是磨砂玻璃底：一个半透明白色圆角卡片盖在桌面壁纸上，
**添加到桌面时会弹出滑块，可以自己调节不透明度**（越往右越"磨砂"，越往左越透明，
接近截图里那种能透出壁纸细节的效果）。每个小组件实例的透明度是单独保存的，
桌面上放好几个可以各自设成不同的透明度。

## 权限

**不申请任何权限**，AndroidManifest.xml 里没有一条 `<uses-permission>`：

- 时间/日期用系统自带的 `TextClock`，自动走系统时钟，不用自己起定时器
- 电量读的是系统的粘性广播 `ACTION_BATTERY_CHANGED`，这个不需要任何权限
- 月历是本地用 `java.time` 算出来的，不读系统日历

## 用 GitHub Actions 编译 APK（手机操作流程）

1. 在 GitHub 新建一个仓库（比如叫 `GlassWidgets`）
2. 把这个文件夹里的所有文件上传上去（可以用 GitHub 手机 App 的「上传文件」，
   或者网页版拖拽上传，保持文件夹结构不变）
3. 上传完成后，进入仓库的 **Actions** 标签页
4. 应该会看到一个叫 `Build APK` 的工作流自动跑起来了（如果没自动跑，
   点进去手动点 `Run workflow` 也可以）
5. 等它跑完（一般 3~5 分钟），点进这次运行记录，下面 **Artifacts** 里
   会有一个 `GlassWidgets-debug-apk`，点击下载，是个压缩包，
   解压后里面就是 `app-debug.apk`
6. 手机上直接打开这个 apk 安装即可（小米可能会提示"未知来源"，
   允许安装就行，这个 apk 是用调试签名打的，可以直接装，不需要额外配置签名证书）

## 之后想加的东西，随时可以说

- 想要天气 → 需要加一条 `INTERNET` 权限（目前刻意没加，保持零权限）
- 想要读系统日历上的日程 → 需要加 `READ_CALENDAR` 权限
- 想要计步 → 需要加 `ACTIVITY_RECOGNITION` 权限（小米这类通常还要额外开自启动权限才稳定）
- 想换配色、圆角大小、字体，都是改资源文件，不涉及权限

这三样如果要加，我会单独跟你说清楚加的是什么权限、干什么用，你来决定要不要加。
